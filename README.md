# Better Advancements

A modern, clean replacement for the vanilla Advancements screen, plus an animated
achievement banner.

![Fabric](https://img.shields.io/badge/mod%20loader-Fabric-blue)
![Java 25](https://img.shields.io/badge/java-25-orange)

## Features

- **Full-page advancement browser** — every advancement of the world in one panel,
  with each advancement's progress bar.
- **Search** — filter advancements by name, instantly.
- **Sorting** — by progress, by title, or vanilla order.
- **Categories** — switch between advancement tabs (story, adventure, nether...).
- **Responsive grid** — 2 to 4 cards per row depending on the window size.
- **Pagination** — browse page by page.
- **Animated achievement banner** — when you unlock an advancement, a banner slides
  in from the top center of the screen (golden border for challenges), replacing
  the old corner toast.
- **Client-side only** — works on any server, no server installation needed.

## Install

1. Install the [Fabric Loader](https://fabricmc.net/use/) for your Minecraft version.
2. Drop the mod jar into your `mods` folder.
3. Open the Advancements screen (press `L` by default).

## Building from source

```bash
./gradlew build
```
